# Segmentation-Aware Early Traffic Accident Anticipation from Dashcam Video

Detection (YOLO11m + ByteTrack), segmentation (SegFormer-B2, Cityscapes) and an LSTM risk model for early accident
anticipation on CCD and DoTA, with a benchmark audit. Report draft: `report/report.md`.

## Layout
- `configs/` protocol (`protocol.yaml`) and experiments (`experiments.yaml`)
- `src/features/extract.py` Stage A perception features (resumable, one .npz per video)
- `src/data/loader.py` labels, toa, split schemes, leakage report
- `src/models/nets.py` FrameRNN, RiskNet (baselines, main model, ablations), exponential loss
- `src/eval/metrics.py` AP / mTTA / TTA@R80 (identical to UString / STAGNet evaluation)
- `src/train/run.py` resumable experiment runner; `src/analysis/` tables, figures, early-vs-late, errors, shortcut probe
- `src/demo/render.py` demo clips and storyboards from cached outputs
- `notebooks/` Kaggle notebooks 01 (extract), 02 (train/eval/ablate), 03 (demo), generated by `kaggle/build_*.py`
- `results/` generated tables, figures, demo (see `results/README.md` for the Kaggle runs they come from)
- `archive/ped_intent_jaad/` an earlier, cancelled project (not used)

## Reproduce
1. `kaggle/ccd_download`, `kaggle/dota_download`: download kernels (CPU).
2. `python kaggle/build_extract.py --push`: Stage A on Kaggle (2x T4, ~3.7 h).
3. `python kaggle/build_notebooks.py --push 02`: Stage B (resumable with `--slug NEW --resume-from OLD`).
4. `python kaggle/build_notebooks.py --push 03 --runs-from <stage B slug>`: demo (CPU).
